# VulnScan – Vulnerability Scanner

## About the Project

VulnScan is a mini cybersecurity project created to check websites or networks for common security issues. It helps identify open ports, outdated software versions, and weak security configurations.

I built this project to understand how vulnerability scanning works and get some practical experience with cybersecurity and basic penetration testing.

## Key Features

- Checks for open ports.
- Identifies possible security weaknesses.
- Checks for outdated software versions where supported.
- Generates a simple vulnerability report.

## Technologies Used

- Python
- Networking concepts
- Vulnerability assessment techniques

## Learning Outcome

While working on this project, I learned the basics of vulnerability scanning, open port detection, and how security weaknesses can affect web applications and networks.

## Disclaimer

This project is created for educational purposes only. Use it only on systems and networks where you have permission to perform security testing.
